# macOS and Apple TV apps

SwiftUI apps on the same shared Kotlin core and the same view models as the iOS app (`docs/IOS_APP.md`). Not iPhone ports: the Mac has a
sidebar, a toolbar search field, a menu bar and a resizable window; the Apple TV has the system tab bar, focusable cards and the Siri Remote.

## Build and run

```sh
brew install xcodegen
apple/scripts/build-shared.sh debug                  # the XCFramework (macOS and tvOS slices included)
python3 apple/scripts/sync-strings.py                # only when the Android strings or apple/Resources/apple-strings.json changed
apple/scripts/mac-run.sh -demo                       # TwitchMac on the offline demo data
apple/scripts/mac-run.sh -demo -snapshot /tmp/home.png [-snapshot-mode layer] [-open lunaria] [-tab following] [-push channel:lunaria]
apple/scripts/tv-run.sh -demo -screenshot /tmp/tv.png -wait 10 [-section browse] [-open lunaria]    # Apple TV simulator
(cd apple && xcodegen generate) && xcodebuild test -project apple/TwitchPlayerApple.xcodeproj -scheme TwitchMac -destination 'platform=macOS'
xcodebuild test -project apple/TwitchPlayerApple.xcodeproj -scheme TwitchTV -destination 'platform=tvOS Simulator,name=Apple TV 4K (3rd generation) (at 1080p)'
```

The tvOS simulator runtime is a 3.8 GB download: `xcodebuild -downloadPlatform tvOS`.
Debug launch arguments (compiled out of Release): `-demo`, `-demo-signed-out`, `-tab`, `-push`, `-open`, `-sheet signin`, `-no-animations`;
Mac only: `-search <text>`, `-minimised`, `-snapshot <file.png>` (+ `-snapshot-delay`, `-snapshot-size`, `-snapshot-view settings`, `-snapshot-mode layer`);
tvOS only: `-section home|following|browse|search|settings`.

## What is shared

`apple/Shared/` compiles into all three apps: the bridge (`Bridge/`), the app model and the per-screen view models (`App/`), the AVPlayer controller and the
live/replay/clip playback model (`Player/`), the design helpers (`Design/`: palette, Liquid Glass helpers, images) and, new in this step, `Views/`: cards,
rows, chat list and lines, emote images (UIKit and AppKit variants), the chat composer and the stale banner. The iOS app keeps its own shell and pages
(`apple/iOS/`); the Mac app (`apple/Mac/`) and the Apple TV app (`apple/TV/`) write theirs.
The Apple TV target excludes `Views/SignInSheet.swift` and `Views/ChatComposer.swift` (no pasteboard, no chat typing there).

## macOS (`apple/Mac/`)

- **Shell.** One window (`Window` scene, so the system restores its size, position and selected section). `NavigationSplitView`: a sidebar (Home, Following when
  signed in, Browse) and the section's page in its own `NavigationStack`, kept alive across section changes. The toolbar has the system search field
  (`.searchable`, Cmd+F focuses it) and an account menu. While the search field is active or holds text, the search page replaces the section.
- **Pages.** Adaptive grids of stream cards (hover lift and play glyph, context menu: watch, open channel, open on twitch.tv, copy link), category posters,
  Following with continue watching and offline channels, channel page with schedule, replays, clips and similar channels.
- **Player.** `AVPlayerView` (system transport bar, scrubbing, volume, Picture in Picture, AirPlay, full-screen button) in a pane with a resizable chat
  column (`HSplitView`); the emote picker is a popover next to the input field. Minimising turns the pane into a floating mini player (hover shows play or pause,
  expand, close). The player options menu has quality, audio only, sleep timer, speed (replays) and the chat toggle.
- **Menu bar and keyboard.** Playback menu (Space play or pause, left and right arrows skip 15 s on replays, F full screen, Cmd+Option+M mute, Cmd+Shift+C chat,
  Cmd+Shift+P minimise or expand, Cmd+. close), sidebar sections on Cmd+1...3, Cmd+[ back, Cmd+F search, Cmd+, Settings (a `Settings` scene with General, Playback,
  Chat, Account and About tabs). Now Playing and the media keys come from `PlayerController`.
- **Sandbox.** App Sandbox with the outgoing network entitlement only (`Mac/TwitchMac.entitlements`, generated by XcodeGen). No signing identity, team or
  provisioning profile is committed (ad-hoc signing).

## Apple TV (`apple/TV/`)

- **Shell.** The system top tab bar (Home, Following when signed in, Browse, Search, Settings), one `NavigationStack` per section. `tvPush` lets a card push a
  page on the stack of whichever section it is in.
- **Focus.** Rows are focus sections (`focusSection()`), cards use the system `.card` button style (lift, highlight, parallax feel), everything has a stable id
  (`channelId`, category id) so a refresh keeps the focus where it is. Type is `callout` and up; cards are 400 pt wide; rows start at the 80 pt title-safe edge.
- **Player.** Full-screen `AVPlayerViewController`: the Siri Remote's select, play or pause and swipe to scrub work as on any Apple TV app and Menu leaves the
  player. The app adds transport-bar menu items: chat, quality, audio only, sleep timer. The chat is a read-only panel over the right of the picture (toggled
  from the transport bar); the Apple TV has no chat input.
- **Sign-in.** A large device code, the twitch.tv/activate address and a QR code that opens the activation page with the code filled in (`?device-code=`),
  so nothing has to be typed.
- **Not done.** Top Shelf extension (needs an app group and a data feed), voice search beyond the system dictation key of the search keyboard, the Discover feed.

## Parity (phone app / iOS / Mac / Apple TV)

| Feature | iOS | Mac | Apple TV |
|---|---|---|---|
| Home, Following (continue watching, offline), Browse, Category, Channel | yes | yes | yes |
| Search with recents, live now, filters | yes | yes (toolbar field; filter picker) | yes (system keyboard; no filter row) |
| Player: live, replay, clip over AVPlayer | yes | yes | yes |
| Chat: emotes, badges, replies, notices | yes | yes | read-only overlay (no replies) |
| Chat input, emote picker, `:` suggestions | yes | yes (popover) | no |
| Picture in Picture | wired | system (AVPlayerView) | no |
| Sleep timer, audio only, quality | yes | yes | yes (transport-bar menu) |
| Draggable sheet and mini strip | yes | floating mini player | no (full screen) |
| Sign-in | device code | device code | code and QR |
| Settings | page | Settings window | tab |
| Discover feed, voice search | no | no | no |

## Verified, and not

- Builds: Debug and Release for macOS and the tvOS simulator, Debug for iOS; **20 Swift tests** on macOS, **19** on tvOS, **17** on iOS (the shared ones run in
  each app, plus a few per platform), all on the offline demo data through the real Kotlin presenters.
- Screenshots in `docs/screenshots/tvos/` come from the Apple TV simulator (4K 3rd generation at 1080p, tvOS 27.0) and show every section, the channel page, the
  player with chat and the sign-in screen (all looked at).
- Screenshots in `docs/screenshots/macos/` come from the app rendering its own window (`MacSnapshotRunner`): this machine has no attached display, so a screen
  capture is impossible and the window server never composites. The result has limits: vibrancy is not reproduced (the sidebar's selected row and the Settings tab
  bar come out black or white), video layers are black, and animations and transitions never advance (`-no-animations` turns them off). Only Home, the player with
  chat, the channel page and the Settings window were captured. **The Following, Browse, Category, Search and mini-player pages of the Mac app were not captured**: for them the window render kept showing the first section. I did not find out why (it may be how `cacheDisplay` and the layer tree treat views a section stack hides with `opacity`), so it is not evidence of a bug, and it is not evidence of their absence either. The channel page, which is reached by a push, rendered correctly; the same view models and shared tests cover the other pages.
- Not verified: a real Mac window with a display (vibrancy, hover, context menus, menu shortcuts, full screen, native Picture in Picture), a real Apple TV and
  Siri Remote (focus feel, parallax, transport-bar menus on hardware), a real Twitch account, real HLS playback, VoiceOver passes, RTL screenshots, Xcode
  stable releases.
