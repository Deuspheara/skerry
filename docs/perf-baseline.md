beyond that spread, repeated on a second run.

## Real TV (documented, not re-run in this pass)

TCL Smart TV Pro (MT5896, Android 14), release build via `benchmark/tools/install-release.sh`
(see docs/PERFORMANCE.md): first frame ~475 ms, Home content ~520 ms with the snapshot. The TV was not touched during
this baseline because the benchmark variant shares the application id with the installed release build.
Re-measure on the TV with `install-release.sh` after the migration; it is the number that matters.

## Regression policy

Any of these is a blocker for Phase 1: release APK or dex size growth beyond ~3 %, baseline profile no longer packaged,
startup profile not applied (startup classes missing from `classes.dex`), `-keep` rules added in the app, analyzer
scores dropping more than 0.5 points, cold start median (with profile) above 340 ms full display on the emulator
across two runs, or a clear frame-timing shift beyond the noise above.
